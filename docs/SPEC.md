# Бастау — SPEC

«Бастау» (каз. «начало») — приложение, которое доводит новичка до первой работающей программы за один заход и не даёт забыть выученное.

## Цель и не-цели

**Цель v1:** человек без опыта за 15–25 минут пишет и запускает `Hello, World!` сам (не по шпаргалке), понимает каждую часть строки, умеет прочитать типичную ошибку, и получает расписание повторений на следующие недели.

**Не-цели v1:** аккаунты, сервер, соревнования, чат, платежи. Только один урок («День 1»); остальные дни помечены «скоро» и не имитируют готовность.

## Решения по умолчанию (озвучены, можно менять)

| Вопрос | Решение |
|---|---|
| Платформа | Веб + PWA, работает на телефоне и ПК, без сборки и без сервера |
| Данные | Только в `localStorage` устройства, экспорт/импорт JSON. Никаких персональных данных наружу |
| Языки кода | Python (Pyodide, подгружается с CDN при первом запуске, затем кэш) и JavaScript (родной, мгновенно, офлайн) |
| Язык интерфейса | Русский. Тексты вынесены в `js/course.js`, KZ — после проверки носителем |
| Исполнение кода | Только собственный код пользователя в отдельном Worker с таймаутом 5 с; Worker не видит `localStorage` |

## Методики → что в приложении

Колонка «Надёжность» — честная оценка того, что я реально прочитал (аннотация/пересказ, не полный текст) и насколько данные общие.

| Принцип | Где в приложении | Источник | Надёжность |
|---|---|---|---|
| Практика с проверкой памяти (testing effect) и распределённое повторение — единственные два «высокополезных» приёма из 10 | Нет перечитывания: любое повторение — вспомнить/написать самому. Карточки на +1, +3, +7, +16, +35, +90 дней | [Dunlosky и др. 2013 (обзор APS)](https://www.psychologicalscience.org/news/releases/which-study-strategies-make-the-grade.html); [Roediger & Karpicke 2006](https://psychology.ecu.edu/wp-content/pv-uploads/sites/216/2019/03/Roediger-Karpicke-2006.pdf) | Сильная. Читал аннотации/пересказы. Те, кто перечитывал, были увереннее, но помнили хуже — поэтому приложение показывает *калибровку* уверенности |
| Оптимальный интервал растёт вместе со сроком, на который надо помнить | Интервалы расширяются; точные числа — эвристика, не из статьи | [Cepeda и др. 2006, 317 экспериментов](https://pubmed.ncbi.nlm.nih.gov/16719566/) | Сильная по принципу; конкретные дни — моё допущение |
| Сначала предсказание, потом запуск (PRIMM: Predict–Run–Investigate–Modify–Make) | Шаги «Предскажи → Запусти → Разбор → Измени → Напиши сам» | [Sentance, Waite 2017–2019 (QMUL)](https://qmro.qmul.ac.uk/xmlui/handle/123456789/57800) | Умеренная: одно исследование с контрольной группой (493 ученика 11–14 лет), без метаанализа; шаг «Make» тяжёл на сложных задачах |
| Неудачная попытка *с последующим ответом* улучшает запоминание (pretesting) | Предсказание до объяснения; «не знаю» разрешено без штрафа | [Kornell, Hays, Bjork 2009](https://pubmed.ncbi.nlm.nih.gov/19751074/) (страница PubMed — Richland, Kornell, Kao 2009 на ту же тему) | Хорошая, но только при немедленной обратной связи |
| Разобранные примеры + постепенное «выцветание» подсказок; для опытных пошаговый разбор вредит (expertise reversal) | Разбор строки по частям у новичка; ответ «уже пишу код» пропускает разбор/конструктор | [Kalyuga и др. — обзор](https://en.wikipedia.org/wiki/Worked-example_effect) (вторичный источник, первичные статьи не открывал) | Средняя: основные данные из математики/физики, для программирования — в основном теоретические работы |
| Для новичков нужна явная поддержка, а не «разберись сам» | Лесенка подсказок, структурные заготовки | [Kirschner, Sweller, Clark 2006 (версия AFT)](https://www.aft.org/sites/default/files/GuidedInstruction.pdf) | Спорная в сообществе (есть критика про problem-based learning) |
| Подписи подцелей (subgoal labels) улучшают результат и перенос в программировании | В разборе каждая часть кода подписана по роли («команда», «что показать», «текст») | [Margulieux, Guzdial, Catrambone 2012](https://appinventor.mit.edu/explore/resources/subgoal-labeled-instructional-material.html) | Умеренная: небольшие выборки (напр. n=40) |
| Задачи «Парсонса» (собрать из готовых строк) быстрее, чем писать с нуля, при тех же приростах знаний | Шаг «Собери строку из блоков» с лишним блоком `Print` | [Multi-institutional Parsons problems (ITiCSE-WG)](https://repository.falmouth.ac.uk/5216/) | Умеренная: в основном одна исследовательская группа |
| Самообъяснение | Шаг «Объясни своими словами» + эталон для сравнения | [Bisra и др. 2018 (метаанализ, 64 исследования)](https://doi.org/10.1007/s10648-018-9434-x) | Хорошая. Размер эффекта (g≈0.55) видел только во вторичных пересказах |
| Гиперкоррекция: ошибки, в которых человек *был уверен*, исправляются лучше | Перед ответом — «Уверен / Скорее да / Угадываю»; уверенная ошибка подсвечивается | Butterfield & Metcalfe 2001, *J. Exp. Psychol.: LMC* (прямой ссылки не даю: в выдаче поиска не нашёл страницу именно этой статьи; сам эффект подтверждён в нескольких обзорах) | Хорошая, воспроизводилась многократно; зависит от типа вопросов |
| Implementation intentions «когда и где» | Финальный шаг: выбрать время на завтра → .ics-напоминание | [Gollwitzer & Sheeran 2006, d≈0.65](https://doi.org/10.1016/S0065-2601(06)38002-1) | Средняя: усреднение по очень разным областям |
| Привычка складывается долго, один пропуск её не ломает | «Мягкая серия»: один пропущенный день подряд не обнуляет серию; цель — 5 минут | [Lally и др. 2010](https://doi.org/10.1002/ejsp.674) | Слабая-средняя: 82 завершивших, разброс 18–254 дня |
| Чередование | Карточки повторения перемешаны между понятиями | [Brunmair & Richter 2019, g≈0.42](https://pubmed.ncbi.nlm.nih.gov/31556629/) | Неоднородная (I²≈77%): для словесного материала эффект отрицательный |

**Чего приложение сознательно не делает:** очки/уровни/рейтинги (внешняя мотивация легко вытесняет интерес, а доказательств пользы для обучения у меня нет), «стили обучения» (не подтверждаются), перечитывание и подсветка как способ учёбы.

## Сценарии (user stories)

1. Впервые открыв приложение, я выбираю язык (Python/JS) и опыт, и сразу попадаю в урок — без регистрации.
2. Я предсказываю вывод, запускаю код и вижу, прав ли я.
3. Я разбираю строку по частям, собираю её из блоков, заполняю пропуск.
4. Я меняю готовую программу, чиню сломанную, пишу с нуля; подсказки открываются после попытки.
5. Я вижу настоящую ошибку Python/JS и человеческое объяснение рядом.
6. Закрыв вкладку на середине, я возвращаюсь к тому же шагу.
7. Завтра приложение само говорит, что пора повторить, и даёт 5 минут карточек.
8. Я экспортирую прогресс файлом и могу восстановить его на другом устройстве.
9. Во вкладке «Примеры» я вижу реальные фрагменты программ, которые мне сделали, с пояснениями и связью с уроком, и могу запустить часть из них.

## Критерии приёмки

- Урок проходится целиком в Edge на 375/768/1440 px, light и dark, без ошибок в консоли.
- Правильный `print("Hello, World!")` засчитывается; 5 типовых неверных ответов дают конкретную, а не общую подсказку.
- Умные кавычки с телефона не ломают запуск.
- Бесконечный цикл останавливается за 5 с и не вешает страницу.
- Интервалы повторений, серия, проверка вывода, подсветка кода покрыты юнит-тестами (`node --test`).
- Прогресс переживает перезагрузку; повреждённый JSON в `localStorage` не ломает запуск.
- Контраст текста ≥ 4.5:1, зоны нажатия ≥ 44 px, работает с клавиатуры, учитывает `prefers-reduced-motion`.

## Безопасность (кратко)

Нет сервера, нет аккаунтов, нет секретов. Весь пользовательский текст попадает в DOM только через `textContent` или экранирование (`Core.esc`). CSP через `<meta>` без `unsafe-inline` для скриптов. Код пользователя выполняется в Worker (нет доступа к `localStorage`/DOM страницы). Импорт JSON проходит проверку формы. Принятый риск: Python-Worker подгружает Pyodide с `cdn.jsdelivr.net` (SRI для `importScripts` невозможен); версия закреплена.
