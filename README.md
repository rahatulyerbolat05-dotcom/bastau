# Бастау

Приложение, которое за ~20 минут доводит новичка до первой работающей программы (`Hello, World!`) и дальше не даёт забыть выученное. Python (Pyodide) и JavaScript запускаются прямо в браузере. Без регистрации и сервера: прогресс хранится только на устройстве.

Подробности: [docs/SPEC.md](docs/SPEC.md) — методики, источники и честная оценка их надёжности.

## Запуск

Двойной клик по `start.bat` (нужен Python 3) — поднимет локальный сервер на `http://127.0.0.1:8830` и откроет браузер.

Или вручную:

```bash
python -m http.server 8830 --bind 127.0.0.1
```

> Открывать `index.html` двойным кликом (`file://`) нельзя: Worker'ы с кодом не стартуют из `file://`.

Python загружается с CDN (jsDelivr, Pyodide 0.26.4, ≈10 МБ) при первом запуске Python-кода и дальше кэшируется. JavaScript работает мгновенно и без интернета.

## Проверка

```bash
node --test tests/core.test.js tests/examples.test.js tests/course.test.js tests/diagnose.test.js
```

Покрыто: интервалы повторений, мягкая серия, проверка вывода/пропусков/блоков, подсветка кода (в т. ч. экранирование HTML), объяснения ошибок, `.ics`, проверка импорта.

- `tests/course.test.js` запускает решения, «сломанные» старты и обходные ответы каждого шага всех уроков на настоящих Python и Node, сверяет заявленные выводы в вопросах и предсказаниях с реальными.
- `tests/diagnose.test.js` — 69 типичных ошибок новичка: каждая реально запускается, и на каждую должна быть конкретная подсказка «Что исправить».

Сквозные прогоны в браузере (`tests/browser-*.js`) вставляются тегом `<script>` на открытую страницу (CSP запрещает `eval`):

- `browser-lesson.js` — `__e2e('py'|'js', 'new'|'pro')` проходит весь урок реальными кликами по DOM;
- `contrast-check.js` — `__contrast()` проверяет контраст токенов (WCAG AA) в текущей теме.

## Раздел «Примеры»

Вкладка «Примеры» показывает реальные фрагменты из программ, которые я для тебя писал (Қalta, расписания, список покупок, задания группы, скрипты уборки, транскрибатор и сам Бастау): как программа устроена, номера строк, пояснения «на что смотреть» и связь с уроком. У части фрагментов есть кнопка «Запустить в песочнице».

Код не копируется руками: `tools/build-examples.js` достаёт его из исходников по номерам строк из `tools/examples-spec.js`, падает, если строка уехала, и реально запускает демо-примеры (JS в `vm`, Python через `python`), сверяя вывод. Результат — `js/examples-data.js`.

```bash
node tools/build-examples.js   # на ПК, где лежат исходники (пути в tools/examples-spec.js)
```

В публичное приложение не попадают имена преподавателей, предметы, класс школьника, ключи и закрытые ссылки (это проверяет `tests/examples.test.js`).

## Структура

| Файл | Роль |
|---|---|
| `js/core.js` | Чистая логика без DOM (тестируется в Node): повторения, серия, проверка, подсветка, `.ics` |
| `js/store.js` | `localStorage` с защитой от порчи (копия битых данных в `bastau.v1.corrupt`) |
| `js/runner.js`, `js/py-worker.js`, `js/js-worker.js` | Запуск кода в Worker'ах, таймаут 5 с |
| `js/course.js` | Содержание урока, карточки, источники |
| `js/steps.js` | Рендеры шагов: предсказание, разбор, блоки, пропуски, код, вопросы, объяснение, план |
| `js/app.js` | Оболочка: вкладки, плеер урока, повторения, песочница, прогресс |
| `css/app.css` | Токены (светлая/тёмная темы) → компоненты → экраны |

## Уроки

Готовы пять дней: «Hello, World!», «Переменные и типы данных», «Условия: если… иначе», «Циклы: повторяй, пока…» (while) и «Цикл for: повтори N раз». На вкладке «Сегодня» главным показан первый непройденный день; у него есть кнопка «Пропустить — я это уже умею», а пропущенный день остаётся в списке «Дни курса» и открывается в любой момент. Следующие дни («Списки», «Функции») помечены «скоро». Прогресс считается отдельно для Python и JavaScript; если выбран язык без прогресса, а на другом он есть, «Сегодня» предлагает переключиться.

## Аккаунт и облачное сохранение

Вход через Google необязателен. Без него прогресс хранится только на устройстве. После входа он сохраняется в Firestore проекта `bastau-by-yerbo` (документ `progress/{uid}`) и сливается между устройствами.

| Файл | Роль |
|---|---|
| `js/firebase-config.js` | Публичные настройки проекта Firebase (`null` выключает вход) |
| `js/account.js` | Вход (Firebase Auth, SDK 10.14.1 с gstatic, грузится только при входе), перенос гостевого прогресса, запуск обмена |
| `js/cloud.js` | Обмен с Firestore по REST: забрать → слить → записать с условием `updateTime`; при конфликте читает заново |
| `Core.mergeState` | Слияние двух состояний: не зависит от порядка, повтор ничего не меняет |
| `firestore.rules` | Доступ только владельцу документа |

- Прогресс гостя лежит в `localStorage` под ключом `bastau.v1`, прогресс аккаунта — под `bastau.v1.u.<uid>`. Выход возвращает гостевой прогресс; копия аккаунта стирается с устройства, если всё успело сохраниться.
- «Пройти заново» (`rev`) и «Стереть прогресс» (`epoch`) несут отметку времени и побеждают более старые данные на других устройствах.
- Пока открыт урок, обмен откладывается: прогресс под уроком не подменяется.
- Черновики «Песочницы» в облако не уходят.
- Настройки по умолчанию (пустой аккаунт, новое устройство) не побеждают выбранные: язык не сбрасывается при входе.
- Прогресс устройства, сделанный без входа, можно добавить в аккаунт в любой момент (кнопка в блоке аккаунта), а не только в момент входа.

Правила выкладываются отдельно от сайта:

```bash
npx firebase-tools deploy --only firestore:rules
```

В консоли Firebase должны быть включены: Authentication → Sign-in method → Google, и домен сайта в Authentication → Settings → Authorized domains.

Тесты: `tests/cloud.test.js` (слияние, обмен с подставным Firestore, конфликты, нет сети, испорченные данные, CSP и правила) и `tests/account.test.js` (вход, перенос прогресса, два аккаунта на одном устройстве, выход, перезапуск).

## Нестандартные ситуации

- **«Что исправить».** `Core.diagnose(lang, code, error)` смотрит не только на текст ошибки, но и на сам код: скобки вместо `=`, русская буква вместо английской, опечатка в имени, команда из другого языка, забытое двоеточие или отступ, лишняя скобка, `input()`/`prompt()` и т. д. Если шаблон не найден — `explainError` по тексту ошибки, затем общее объяснение с номером строки (`Core.friendlyError`).
- **Бесконечный цикл.** Исполнители обрывают программу после 2000 строк вывода (и через 5 с без вывода) с понятным объяснением.
- **«Не понял? Объясню проще».** У шага может быть поле `simple` (текст или `{text, code, after}`) — второе объяснение через бытовое сравнение. В повторении не показывается.
- **Редактор.** Автоотступ после `:` (Python) и `{` (JavaScript), Backspace убирает уровень отступа, на телефоне есть клавиша «отступ».

## Как добавить следующий день

1. В `js/course.js` написать `buildХ(lang)` по образцу `buildCond()` (помощники — в `kit(lang)`) — шаги тех же типов, карточки с уникальными `card`-id (между уроками они не должны повторяться), и добавить запись в `LESSONS` и `BUILDERS`. Убрать день из `ROADMAP`.
2. Решения и «сломанные» старты проверит `tests/course.test.js tests/diagnose.test.js`: он запускает их на настоящих Python и Node. Запусти тесты.
3. Карточки подхватятся автоматически: повторение берёт их из `Course.allCards(lang)`.
4. Поднять `?v=N` в `index.html`, `sw.js` и `js/runner.js` (адреса воркеров).

## Публикация

Это статический сайт: подойдёт GitHub Pages или любой хостинг. `sw.js` регистрируется только на HTTPS/localhost и кэширует оболочку (сеть сначала) и Pyodide (кэш сначала). При изменении файлов поднимай `?v=N` в `index.html`, `sw.js` и `js/runner.js`.

## Известные ограничения

- Python-код требует интернета при самом первом запуске.
- Пять уроков; следующие дни помечены «скоро».
- Вход через Google открывает всплывающее окно: если браузер его блокирует, приложение просит разрешить окна. Вход по перенаправлению не используется.
- Ввода с клавиатуры (`input()`, `prompt()`) нет: код выполняется в Worker. Приложение объясняет это и предлагает задать значение в коде.
- Интерфейс только на русском (каз. термины требуют проверки носителем).
- Исполнение пользовательского кода — в Worker без доступа к `localStorage`/DOM. `importScripts` с CDN не поддерживает SRI; версия Pyodide закреплена.
