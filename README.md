# Бастау

Приложение, которое за ~20 минут доводит новичка до первой работающей программы (`Hello, World!`) и дальше не даёт забыть выученное. Python (Pyodide) и JavaScript запускаются прямо в браузере. Без регистрации и сервера: прогресс хранится только на устройстве.

Подробности: [docs/SPEC.md](docs/SPEC.md) — методики, источники и честная оценка их надёжности.

## Запуск

Двойной клик по `start.bat` (нужен Python 3) — поднимет локальный сервер на `http://127.0.0.1:8830` и откроет браузер.

Или вручную:

```bash
python -m http.server 8830 --bind 127.0.0.1
```

> Открывать `index.html` двойным кликом (`file://`) нельзя: Worker'ы с кодом не стартуют из `file://`.

Python загружается с CDN (jsDelivr, Pyodide 0.26.4, ≈10 МБ) при первом запуске Python-кода и дальше кэшируется. JavaScript работает мгновенно и без интернета.

## Проверка

```bash
node --test tests/core.test.js tests/examples.test.js tests/course.test.js tests/diagnose.test.js
```

Покрыто: интервалы повторений, мягкая серия, проверка вывода/пропусков/блоков, подсветка кода (в т. ч. экранирование HTML), объяснения ошибок, `.ics`, проверка импорта.

Сквозные прогоны в браузере (`tests/browser-*.js`) вставляются тегом `<script>` на открытую страницу (CSP запрещает `eval`):

- `browser-lesson.js` — `__e2e('py'|'js', 'new'|'pro')` проходит весь урок реальными кликами по DOM;
- `contrast-check.js` — `__contrast()` проверяет контраст токенов (WCAG AA) в текущей теме.

## Раздел «Примеры»

Вкладка «Примеры» показывает реальные фрагменты из программ, которые я для тебя писал (Қalta, расписания, список покупок, задания группы, скрипты уборки, транскрибатор и сам Бастау): как программа устроена, номера строк, пояснения «на что смотреть» и связь с уроком. У части фрагментов есть кнопка «Запустить в песочнице».

Код не копируется руками: `tools/build-examples.js` достаёт его из исходников по номерам строк из `tools/examples-spec.js`, падает, если строка уехала, и реально запускает демо-примеры (JS в `vm`, Python через `python`), сверяя вывод. Результат — `js/examples-data.js`.

```bash
node tools/build-examples.js   # на ПК, где лежат исходники (пути в tools/examples-spec.js)
```

В публичное приложение не попадают имена преподавателей, предметы, класс школьника, ключи и закрытые ссылки (это проверяет `tests/examples.test.js`).

## Структура

| Файл | Роль |
|---|---|
| `js/core.js` | Чистая логика без DOM (тестируется в Node): повторения, серия, проверка, подсветка, `.ics` |
| `js/store.js` | `localStorage` с защитой от порчи (копия битых данных в `bastau.v1.corrupt`) |
| `js/runner.js`, `js/py-worker.js`, `js/js-worker.js` | Запуск кода в Worker'ах, таймаут 5 с |
| `js/course.js` | Содержание урока, карточки, источники |
| `js/steps.js` | Рендеры шагов: предсказание, разбор, блоки, пропуски, код, вопросы, объяснение, план |
| `js/app.js` | Оболочка: вкладки, плеер урока, повторения, песочница, прогресс |
| `css/app.css` | Токены (светлая/тёмная темы) → компоненты → экраны |

## Уроки

Готовы два дня: «Hello, World!» и «Переменные и типы данных». На вкладке «Сегодня» главным показан первый непройденный день; у него есть кнопка «Пропустить — я это уже умею», а пропущенный день остаётся в списке «Дни курса» и открывается в любой момент. Дни 3–4 помечены «скоро».

## Как добавить следующий день

1. В `js/course.js` написать `buildХ(lang)` по образцу `buildVars()` — шаги тех же типов, карточки с уникальными `card`-id (между уроками они не должны повторяться), и добавить запись в `LESSONS` и диспетчер `build(lang, id)`. Убрать день из `ROADMAP`.
2. Решения и «сломанные» старты проверит `tests/course.test.js tests/diagnose.test.js`: он запускает их на настоящих Python и Node. Запусти тесты.
3. Карточки подхватятся автоматически: повторение берёт их из `Course.allCards(lang)`.
4. Поднять `?v=N` в `index.html` и `sw.js`.

## Публикация

Это статический сайт: подойдёт GitHub Pages или любой хостинг. `sw.js` регистрируется только на HTTPS/localhost и кэширует оболочку (сеть сначала) и Pyodide (кэш сначала). При изменении файлов поднимай `?v=N` в `index.html` и `sw.js`.

## Известные ограничения

- Python-код требует интернета при самом первом запуске.
- Два урока; дни 3–4 помечены «скоро».
- Интерфейс только на русском (каз. термины требуют проверки носителем).
- Исполнение пользовательского кода — в Worker без доступа к `localStorage`/DOM. `importScripts` с CDN не поддерживает SRI; версия Pyodide закреплена.
